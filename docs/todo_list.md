# 功能计划

- 主界面自定义创建多个窗口，log和终端; 
  - 多窗口，需要更多地支持键盘操作；
- 同时监控多个文件，即，过滤条件应用到多个文件中；
  - 不只是日志文件，还可以监控特定文件；
- 日志界面支持类似Vim的操作；
  - 或者说整个工具都需要支持Vim，可以进行纯键盘操作；
- 监控某个进程的标准输出；
  - 例如本地调试Log捕获；
- 实现完整的终端；
- 导入文件夹，支持命令行打开，例如VSCode的 code .；
- 接入AI，做一个小型的“Agent”，进一步形成自动化Debug流？；
- 同时监控多个文件，所有文件内容，可以输出到同一个列表中；
  - 监控数据流在所有模块的行程；
